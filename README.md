# Titus Client

Titus Client is a custom client/launcher for Minecraft: Java Edition, currently in development.

## Features
- Secure sign-in with your own Microsoft account (official OAuth device code flow)
- Launches Minecraft: Java Edition with your legitimately purchased license
- No passwords are stored; tokens are only used to authenticate your own session
